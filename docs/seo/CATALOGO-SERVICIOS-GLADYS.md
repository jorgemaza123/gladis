## Reglas aplicadas

- Cada servicio puede cotizarse por separado o añadirse a una consulta combinada.
- El servicio principal determina el equipo que recibe todo el mensaje de WhatsApp.
- Los servicios `partner` se identifican como coordinados con un aliado.
- No se publican precios, marcas, disponibilidad, inventario ni experiencia no verificados.
- No se crearon páginas separadas para variantes menores; cada ficha funciona como página pilar.
